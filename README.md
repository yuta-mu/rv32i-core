# rv32i-core

OCamlによる独自言語コンパイラとRV32I命令セットを処理するハードウェアを製作し，独自命令と専用アクセラレータ回路による演算の高速化を検証するプロジェクト実験．

## プロジェクトの目標

汎用的なRV32I基本命令を拡張し，ソフトウェアとハードウェアの協調設計による性能向上を目的とする．

* **アクセラレータ対象**: 特定の計算負荷の高い演算(例: 行列積 / 積和演算 / 暗号処理 など)
* **独自命令の導入**: RISC-Vのカスタム予約領域(`custom-0`等)を用いた専用命令の定義
* **性能評価**: 標準RV32I命令列と独自拡張命令列における実行サイクル数の比較

## ディレクトリ構成

* `compiler/`: OCaml自作コンパイラ(独自命令のコード生成)
* `hw/`: VerilogによるRV32I CPUコアおよび専用アクセラレータ回路
* `bsp/`: ベアメタル実行基盤(リンカスクリプト，スタートアップコード)
* `tests/`: 動作検証用コードおよびベンチマークプログラム
